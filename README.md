# Mastermind AI – Stock Market Advisor 📈🤖

Mastermind AI is a backend-focused **AI-powered stock market advisory system** built using **Java, Spring Boot, and Spring AI**.  
It provides real-time market data, AI-driven stock analysis, market sentiment, and daily summaries to help users understand market trends better.

---

## 🚀 Features

- 📊 **Live Market Data**
  - Fetches real-time index data (NIFTY 50, Bank Nifty, etc.)
  - Calculates price change and percentage movement

- 🤖 **AI-Based Stock Analysis**
  - Uses Spring AI to generate intelligent stock insights
  - Explains market movement in simple language

- 📰 **Market News Integration**
  - Fetches latest stock and market-related news
  - Helps correlate news with market movement

- 📈 **Market Sentiment Analysis**
  - Determines overall market sentiment (Bullish / Bearish / Neutral)

- ⏰ **Daily Market Summary**
  - Automatically generates daily market summary using a scheduler

- 🔌 **RESTful APIs**
  - Clean and modular REST APIs for market data, AI chat, and summaries

---

## 🛠️ Tech Stack

- **Backend:** Java, Spring Boot
- **AI Integration:** Spring AI
- **API Communication:** REST APIs
- **Scheduling:** Spring Scheduler
- **Build Tool:** Maven
- **Version Control:** Git & GitHub
